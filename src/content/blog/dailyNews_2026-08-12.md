![A simple fix for LLM tail latency: send each request twice](https://engineering.myhoai.com/posts/a-simple-fix-for-llm-tail-latency/index.png)

**Overview:** Proposes a cost-effective alternative to priority-tier LLM services for reducing tail latency in realtime systems like voice agents. **Method:** Duplicates each LLM request and accepts the faster response, exploiting the rarity and independence of slow responses. **Results:** Benchmarked on 50 production requests: worst-case time to complete dropped from 9.8s to 3.5s; worst-case time to first token from 4.2s to 1.2s; median matched priority tier. Reduces 10-second silences in 25-turn calls from ~22% to near zero. **Impact:** Demonstrates that request duplication can outperform paid priority tiers for tail latency at standard-tier cost, with implications for interactive LLM deployments.

### [CurveFP: Algebraically Closed Low-Precision Arithmetic for Efficient Language Model Training and Inference](https://arxiv.org/abs/2608.10010)

<small>**cs.LG updates on arXiv.org** &nbsp;·&nbsp; 2026-08-12 05:00:00 &nbsp;·&nbsp; `low-precision-arithmetic` `quantization` `language-model-training` `numerical-methods`</small>

**Overview:** Introduces CurveFP, a closed-product codebook family for low-precision arithmetic that optimizes both scalar fidelity and arithmetic operations. **Method:** Distributes quantized magnitudes across interleaved logarithmic curves with a rational radix, ensuring algebraic closure for products via sign XOR and integer-index updates. Implemented as CurveFP eight (E4C3/E5C2) for training and CurveFP seven (E3C3) for deployment. **Results:** CurveFP seven achieves better perplexity than FP8 with one fewer bit and stays within 1.32% of native quality. CurveFP eight reduces NMSE in all 36 GEMM comparisons and matches BF16 inference perplexity (22.5366 vs 22.5407) in pretraining experiments. **Impact:** Establishes a new paradigm for low-precision arithmetic that combines FP8-class performance with simpler product paths, enabling efficient training and deployment of large language models.

### [Transformer Geometry Observatory-IV: Persistent Homology for Representation Evolution Analysis](https://arxiv.org/abs/2608.09997)

**Overview:** This work introduces Transformer Geometry Observatory-IV (TGO-IV), a topological framework to analyze how Transformer representations evolve across layers using Persistent Homology. It addresses the underexplored question of how raw input representations transform into task-relevant features by studying the global topological structure of token-level representation point clouds. **Method:** TGO-IV constructs Vietoris-Rips simplicial complexes from layer-wise representation point clouds and computes topological signatures including Persistence Diagrams, Barcode Diagrams, Betti Curves, Persistence Landscapes, Bottleneck Distance, and Wasserstein Distance. These tools quantify the evolution of global topology across Transformer layers. **Results:** The framework provides a comprehensive analysis of representation manifold evolution, enabling isolation of critical layers and trends in feature development. **Impact:** Advances interpretability research by introducing a novel topological lens to study Transformer dynamics, opening new avenues for understanding and optimizing deep learning models.

**Overview:** Proposes Sheaf-based Federated Representation Learning (SFRL), a framework for learning informative representations in heterogeneous federated systems without assuming a shared global latent space. **Method:** Uses learnable sheaf restriction maps to enforce manifold-constrained geometric alignment via a quadratic gluing regularizer (sheaf Laplacian). **Overview:** This paper develops a formal framework for constructing canonical interpretations from plural structure theories, addressing non-determinism in logical systems. **Method:** A structure theory is defined as a triple (Σ, A, I), with three levels of canonicalization: closure stabilization, global completion, and determinization. Non-determinism is classified into epistemic (Type E) and structural (Type S) plurality, with Type S-strong theories enabling determinization via canonical selection. It also shows that multi-level canonicalization forms a non-commutative system and applies the framework to LLM-assisted reasoning, interpreting hallucinations as unsupported canonicalization. **Impact:** Provides a foundational tool for formal reasoning in plural logics and AI systems, with potential applications in theorem proving and explainable AI.

### [MarkNull: Model-Agnostic Watermark Removal via Latent-Space Manipulation](https://arxiv.org/abs/2608.10166)

<small>**cs.CR updates on arXiv.org** &nbsp;·&nbsp; 2026-08-12 05:00:00 &nbsp;·&nbsp; `digital-watermarking` `adversarial-attacks` `AI-generated-content` `latent-manipulation`</small>

**Overview:** This paper introduces MarkNull, a model-agnostic attack to remove watermarks from AI-generated imagery while preserving visual quality. The work addresses a critical gap in watermark robustness, demonstrating that existing defenses are vulnerable to latent-space manipulation. **Method:** MarkNull exploits a statistical dependency between the latent representation and embedded watermark noise, quantified via the Noise-Latent Alignment Score (NLAS). The attack optimizes to decorrelate the latent from the watermark while maintaining semantic fidelity. MarkNull-A, an amortized variant, distills the attack into a single forward pass (0.50s/image). **Results:** Across multiple watermarking paradigms (post-hoc, fine-tuning-based, initial-noise-based), MarkNull reduces bit accuracy to 53.14% (near random guessing) without perceptible degradation. It successfully compromises Google’s SynthID-Image and transfers to video watermarking. **Impact:** This work highlights the fragility of current watermarking schemes and motivates the development of resilient designs. Open questions include defenses against latent-space attacks and broader generalization to other modalities.

### [Measuring and Optimizing GPU LZ77 Decode: The Parse Layer Dominates](https://arxiv.org/abs/2608.10188)

<small>**cs.DC updates on arXiv.org** &nbsp;·&nbsp; 2026-08-12 05:00:00 &nbsp;·&nbsp; `GPU-acceleration` `LZ77-decompression` `parallel-algorithms` `GPU-architecture`</small>

**Overview:** This paper challenges conventional assumptions about GPU LZ77 decompression bottlenecks, revealing that parsing—not copying—dominates decode time. The study provides empirical measurements across three decoder architectures on an NVIDIA H100, offering insights for optimizing lossless compression pipelines. **Method:** The authors analyze parse, copy, and match layers using Nsight profiling, measuring latency distributions and dependencies. Key optimizations include bounding back-reference chain depth (costing 0.006% in compression ratio) and eliminating self-overlapping matches via parallelization. The sequential distance history is removed at a 0.540% ratio cost, increasing dependency-free parse runs. **Results:** Parse holds 64-72% of device-resident decode time; bounding chain depth moves latency by ≤2.8%, while self-overlapping matches are parallelized for 2.75-8.42x speedups. Bus efficiency is limited to 4.4% due to small median matches (7 bytes) vs. 128-byte cache lines. **Impact:** The findings refute ten common hypotheses, provide a machine-checkable record of results, and guide GPU-based compression optimizations, particularly for Zstandard and similar formats.

### [FaCTz: GPU-Based Error-Bounded Lossy Compression with Critical-Point Preservation](https://arxiv.org/abs/2608.10586)

<small>**cs.DC updates on arXiv.org** &nbsp;·&nbsp; 2026-08-12 05:00:00 &nbsp;·&nbsp; `lossy-compression` `scientific-simulation` `GPU-acceleration` `topology-preservation`</small>

**Overview:** This paper presents FaCTz, the first GPU-based error-bounded lossy compressor that guarantees preservation of critical points in vector-field data from scientific simulations. Existing GPU compressors are topology-agnostic, while CPU-based cpSZ preserves topology but at low throughput. **Method:** FaCTz reformulates critical-point preservation as independent parallel tasks, enabling block-wise or speculative per-point processing. It includes two modes: a throughput-optimized block-wise mode and a ratio-optimized speculative mode. The approach leverages GPU parallelism to decouple constraints that were previously sequential. **Results:** FaCTz preserves all critical points while achieving up to 60 GB/s throughput—640x faster than cpSZ’s multithreaded CPU implementation. Its speculative mode improves compression ratio by ~2x over the throughput-oriented mode. **Impact:** FaCTz bridges the gap between high-throughput GPU compression and topology-aware requirements, enabling scalable analysis of large-scale simulations without sacrificing critical feature integrity.

**Overview:** Introduces N2NMatcher, a framework for program-level binary code similarity analysis (BCSA) that addresses challenges posed by function inlining, which disrupts traditional function call graph (FCG)-based decomposition methods. **Method:** N2NMatcher uses a hierarchical graph neural network (GNN) to predict anchor functions (stable modules across compilations) from binary representations combining opcode sequences, control-flow structures, and FCG context (ACFG-FCG). ### [Self-Evolving Harnesses: Disentangling Model Gaps and Language-Specific Engineering](https://arxiv.org/abs/2608.10178)

<small>**cs.SE updates on arXiv.org** &nbsp;·&nbsp; 2026-08-12 05:00:00 &nbsp;·&nbsp; `self-evolving-agents` `programming-languages` `code-generation`</small>

**Overview:** Studies self-evolving harnesses (closed-loop agents that edit prompts/tools/memory) across 8 programming languages and 3 base models to analyze what evolved artifacts encode. **Method:** Uses a fixed evolution recipe with typed failure signals to attribute modifications.
