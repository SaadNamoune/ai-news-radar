### [AgentJailbreak: Exploiting Enterprise Coding Agents via Adversarial Skill Synthesis](https://arxiv.org/abs/2608.05223)

<small>**cs.SE updates on arXiv.org** &nbsp;·&nbsp; 2026-08-07 05:00:00 &nbsp;·&nbsp; `adversarial-machine-learning` `code-security` `LLM-security` `enterprise-agents`</small>

**Overview:** This paper exposes critical security risks in autonomous coding agents by demonstrating how adversarial skill files can exploit enterprise agents to execute malicious shell commands. The work highlights the gap between intended benign behavior and actual exploitable outcomes in real-world deployments. **Method:** The authors synthesize 2,826 adversarial skills from 471 real-world shell commands using six LLMs across four families, mapping them to 11 MITRE ATT&CK tactics. They evaluate two enterprise-grade agents (Gemini CLI and Qwen Code) across 5,629 runs using a rigorous pipeline with LLM-as-a-judge validation (Cohen's kappa = 0.85 vs. human gold standard). **Results:** Exploitation rates are alarmingly high: 95.5-96.1% for Gemini CLI and 71.6-74.0% for Qwen Code, with explicit safety recognition occurring in only 1.99% of runs. Results are robust across generating models and evaluation conditions. **Impact:** This work advances AI security by quantifying the attack surface of LLM-powered agents and underscores the urgent need for safety mechanisms in enterprise deployments before widespread adoption.

### [Ignition Index: Quantifying Global Workspace Theory in Transformer Language Models](https://arxiv.org/abs/2608.05160)

<small>**cs.AI updates on arXiv.org** &nbsp;·&nbsp; 2026-08-07 05:00:00 &nbsp;·&nbsp; `mechanistic-interpretability` `transformer-architectures` `global-workspace-theory`</small>

**Overview:** Introduces the *Ignition Index (I)*, a scalar metric to operationalize Global Workspace Theory (GWT) in transformer language models, predicting abrupt "ignition" transitions in processing. **Method:** Fits a four-parameter sigmoid to per-layer linear probe accuracy vs. input signal strength, extracting steepness parameter β̂. Validates selectivity (9.6-fold) against shuffled-label controls. **Results:** (1) Feedforward transformers exceed SSMs by 89% in β̂ (p < 1e-13). (2) Huginn-3.5B shows 2.12-fold higher ignition along iteration vs. depth axis. (3) Pythia-410M exhibits a phase transition at training step 256 (+67%). (4) No link to model scale or signal strength. **Impact:** Provides a validated quantitative bridge between GWT and mechanistic interpretability, enabling architecture-level discriminability in scaling laws.

### [Composable Conformal Prediction for Autonomous Security Agent Pipelines](https://arxiv.org/abs/2608.05199)

<small>**cs.CR updates on arXiv.org** &nbsp;·&nbsp; 2026-08-07 05:00:00 &nbsp;·&nbsp; `conformal-prediction` `security-pipelines` `statistical-guarantees`</small>

**Overview:** This paper addresses trajectory-level coverage guarantees for autonomous security agent pipelines (e.g., intrusion detection) where split conformal prediction fails to compose across independently trained stages. The work is critical for deploying reliable multi-stage security systems with finite-sample guarantees. **Method:** The authors derive a valid spanning-tree alternative to Bonferroni allocation for correlated stages, distinguishing between dependent stages and audit-sample sufficiency. They introduce pairwise overlap bounds and analyze coarse-to-fine label selection artifacts that inflate measured correlation. **Results:** On a two-stage intrusion-detection pipeline across 6 LLMs and 2 datasets, removing label-selection artifacts reduces measured correlation from near 1 to 0–0.78. Trajectory failure audits achieve 13.7% tighter bounds than Bonferroni at sufficient sample sizes but degrade when undersized. A modular certificate yields a 0.6% average coverage gain. Average trajectory coverage is 92.7% ± 2.4% at α = 0.10. **Impact:** Demonstrates the fragility of distribution shift in calibrated confidence (100% miscoverage at 78% accuracy) and provides tools for designing composable, auditable security pipelines.

[→ Read full article](https://arxiv.org/abs/2608.05199)

### [RepoOMP: Hybrid Framework for Repository-Aware OpenMP Parallelization](https://arxiv.org/abs/2608.05855)

<small>**cs.DC updates on arXiv.org** &nbsp;·&nbsp; 2026-08-07 05:00:00 &nbsp;·&nbsp; `OpenMP` `parallelization` `code-analysis` `LLM-agent`</small>

**Overview:** Addresses the challenge of OpenMP parallelization in mature repositories by introducing RepoOMP, a hybrid framework that combines deterministic rules with LLM agents to recover parallelization-relevant evidence. **Method:** Builds a Multi-granularity Attributes Performance (MAP) graph to route hotspots between rules and agents, constructs a Structured Transformation Context (STC) to expose dependency facts, and avoids flooding the model with irrelevant repository text. **Results:** Evaluates on 951 hotspots from NPB, BOTS, FFmpeg, NCNN, and GROMACS. Achieves 372 accepted hotspots (330 real-world), with average speedups of 8.23× (NPB) and 8.96× (BOTS). For real-world kernels, achieves 5.25× mean speedup, improves speedup by 18–28%, and reduces agent-side tokens by 47–68% vs. unstructured baselines. Median speedup across 330 accepted hotspots is 2.25×. **Impact:** Provides an evidence-guided, scalable approach to parallelization in repository settings, significantly improving performance and reducing computational overhead in LLM-based code transformation.

### [Fault Localization in Verification-Aware Languages: State-Based vs. Counterexample-Based Strategies](https://arxiv.org/abs/2608.05399)

<small>**cs.SE updates on arXiv.org** &nbsp;·&nbsp; 2026-08-07 05:00:00 &nbsp;·&nbsp; `formal-verification` `Dafny` `fault-localization` `program-analysis`</small>

**Overview:** This paper tackles the challenge of debugging verification failures in verification-aware languages like Dafny by comparing state-based and counterexample-based fault localization strategies. It addresses the gap between error detection and root-cause identification in formal verification workflows. **Method:** The authors implement two paradigms: state-based localization (inferring invariants/predicates to identify suspicious states) and counterexample-based localization (progressively enriching verifier output from raw traces to structured multi-trace aggregation). Evaluation uses MutDafny to generate mutants from DafnyBench, measuring localization effectiveness via EXAM scores. **Results:** Counterexample-based approaches outperform state-based methods, with structured single-trace ranking yielding the largest improvement. Multi-trace aggregation further enhances robustness by reducing solver-induced path bias and increasing coverage. **Impact:** The findings provide actionable insights for improving debugging in verification-aware languages, demonstrating the critical role of counterexample structuring in fault localization.
