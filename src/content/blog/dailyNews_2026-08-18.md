### [Unigram: A bijective byte-to-word codec costing exactly one LLM token per byte](https://github.com/bleugreen/unigram)

<small>**Hacker News - Newest: "llm"** &nbsp;·&nbsp; 2026-08-18 18:58:17 &nbsp;·&nbsp; `tokenization` `codec` `LLM-inference`</small>

![Unigram: A bijective byte-to-word codec costing exactly one LLM token per byte](https://opengraph.githubassets.com/f0d3bfb6a4757fe001089ee1141ed231d841afc86c9145cf24d8faa490ab4c8c/bleugreen/unigram)

**Overview:** Unigram is a bijective codec that encodes arbitrary byte strings into English words such that each byte maps to exactly one LLM token, ensuring predictable token cost (N bytes = N tokens). This addresses the unpredictability of tokenization overhead in LLM prompts and logs. **Method:** The codec uses a 256-entry ASCII word list (4–10 chars) optimized for tokenizer compatibility across major vocabularies (e.g., cl100k_base, o200k_base). Encoding/decoding is reversible with functions like `encode`, `decode`, and `try_mint`. The alphabet is verified for space-prefixed/bare token costs and contextual punctuation handling. **Results:** Benchmarks show Unigram consistently outperforms hex/base64 under GPT vocabularies (e.g., 4 bytes: 4.0 vs 4.5 tokens for base64url under o200k). Token cost is flat (N tokens for N bytes) with at most +1 token for preceding punctuation. **Impact:** Enables deterministic token budgeting for identifiers (e.g., nonces, correlation IDs) in LLM workflows, eliminating variance in prompt engineering. Open questions include broader tokenizer support and integration with retrieval-augmented systems.

### [HyperSAE: High-Performance Hyperbolic Sparse Autoencoders for Mechanistic Interpretability](https://github.com/vishal-dehurdle/hypersae)

<small>**Hacker News - Newest: "llm"** &nbsp;·&nbsp; 2026-08-18 17:53:01 &nbsp;·&nbsp; `sparse-autoencoders` `mechanistic-interpretability` `hyperbolic-embeddings`</small>

![HyperSAE: High-Performance Hyperbolic Sparse Autoencoders for Mechanistic Interpretability](https://opengraph.githubassets.com/55a1b311c96bf3e151e73cac1d861f496355fb3a36ae4440f1fea60792561c49/vishal-dehurdle/hypersae)

**Overview:** HyperSAE introduces hyperbolic sparse autoencoders (SAEs) to improve GPU throughput and interpretability for language model activations. It targets Gemma-2-2B Layer 13 residual streams (d=2304, dict size M=16384) with a novel decoupled weight-space regularization architecture. **Method:** The system separates computation into two speeds: (1) fast RMSNorm-based reconstruction and (2) slow weight-space regularization, preserving model compatibility. Core components include `HyperSAE`, `FlatSAE`, `TriPartiteLoss`, and `CoActivationQueue`. **Results:** Evaluated on 20M tokens of FineWeb-Edu using NVIDIA L4 GPUs, HyperSAE achieves high throughput while maintaining sparse activation fidelity. Benchmarks show improved efficiency over traditional SAEs. **Impact:** Advances mechanistic interpretability by enabling scalable, high-performance SAEs for large language models. Open questions include generalization to other layers/models and optimization of hyperbolic geometry trade-offs.

**Overview:** Introduces Riemannian Hodge Message Passing (RHMP), a physics-informed neural architecture that strictly separates topological conservation laws from geometry-dependent learning for mesh-based physical field prediction. **Method:** RHMP enforces exact cochain-complex identities ($d_{k+1}d_k=0$) via metric-weighted Hodge blocks ($d_k^	op H_{k+1}d_k$) where $H_k$ are learned symmetric positive-definite cochain metrics. The design incorporates cochain-frame equivariance to ensure invariance under orthogonal basis changes. **Results:** Evaluated on seven benchmarks spanning fluids, electromagnetism, gauge fields, and variable-mesh CFD; RHMP achieves best overall performance with largest gains where topology, learned geometry, and field structure interact. **Impact:** Advances physics-informed ML by providing a principled framework for topology-preserving, geometry-adaptive surrogate modeling with provable conservation properties.

### [AccretionLink: Exposure Control Attacks on Private-Attribute Inference via Bounded Selection Odds](https://arxiv.org/abs/2608.14735)

**Overview:** Introduces *AccretionLink*, a novel exposure control attack enabling adversaries to rank authentic public posts to strengthen private-attribute inference without altering content. Defines confidentiality/integrity games and models bounded selection odds via partial identification. **Method:** Constructs dependence-aware time-uniform e-processes for statistical inference under selection constraints. Uses odds-four selection and label-blind model-guided selection to evaluate attack efficacy. **Results:** On 52 synthetic profiles, odds-four selection reduced aggregate negative log likelihood by 0.01595 nats (95% CI [0.00890, 0.02336]) at eight posts, with three of four target effects surviving Holm adjustment. Label-blind selection caused 6/109 high-confidence false reversals. On 142 PAN15 profiles, exploratory selection yielded a 0.01227-nat advantage without reversals. **Impact:** Advances privacy-attack research by formalizing exposure control attacks, demonstrating practical risks in social media inference, and introducing statistical tools (e-processes) for bounded selection scenarios.

### [DDBench: A Benchmark for Distributed-System Debugging with LLM Agents](https://arxiv.org/abs/2608.14863)

**Overview:** DDBench introduces the first benchmark for LLM-based agents to debug distributed-system bugs, addressing a critical gap in evaluation. **Method:** The benchmark includes 60 historical bugs from 13 open-source systems, partitioned into three difficulty tiers. Each case is evaluated under two conditions: symptom-only vs. context-augmented (logs, traces, runtime state). Faithful context can mislead LLMs. **Impact:** Advances distributed-system debugging research, isolates context effects, and reveals reasoning dimensions absent in single-process benchmarks.

### [Forward-Pass-Only MLP Training: High-Throughput LLM Adaptation Without Backpropagation](https://arxiv.org/abs/2608.14563)

**Overview:** Proposes Forward-Pass-Only (FPO) MLP training for LLMs, eliminating backward passes to achieve 2.7–3.2x throughput and ~40% lower peak memory while maintaining in-domain performance. **Method:** FPO exploits late-layer prediction error as a proxy gradient (cosine similarity 0.47–0.59 across six models) via a two-minute diagnostic that identifies viable layers. A single error signal is applied to target layers without inter-layer propagation or autograd graphs. **Results:** On OLMo-2-7B, Qwen3-8B, and Falcon3-7B, FPO improves in-domain perplexity while keeping MMLU, ARC-Challenge, HellaSwag, and Winogrande within seed-noise of baseline. Localizing SFT to FPO layers achieves similar results at 2.2x higher wall-clock cost. **Impact:** Demonstrates practical high-throughput adaptation for LLMs without backpropagation, opening avenues for memory-efficient fine-tuning in resource-constrained settings.
