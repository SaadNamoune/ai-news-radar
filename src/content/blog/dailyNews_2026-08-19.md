**Overview:** A plugin for DeepSeek Harness that implements LLM-as-a-Verifier to grade candidate solutions using a probabilistic tournament selection mechanism. It enables parallel agent attempts with automated scoring (0–1 scale) and selection of the best output. **Method:** Uses a "Probabilistic Pivot Tournament" algorithm to compare N candidates with at most 3(N−1) pairwise gradings (vs. N(N−1)/2 in exhaustive pairwise). The `verify_rollout` tool runs parallel agent sessions, grades outputs, and returns the highest-scoring result. **Results:** No empirical benchmarks provided in the repo, but the implementation matches the LLM-as-a-Verifier paper's methodology with adaptations for DeepSeek Harness (e.g., logprobs sampling due to API limitations). **Impact:** Advances agentic AI workflows by introducing structured, model-driven verification for multi-attempt agentic tasks. **Overview:** This paper demonstrates a critical Spectre attack vulnerability in Cloudflare Workers, bypassing existing mitigations (e.g., timer restrictions, DyPrIs) to leak a JWT token from a co-located victim worker. **Method:** The attack leverages microarchitectural amplification and remote timers to measure time in the production environment, achieving 12 bit/s leakage at 99.16% accuracy—orders of magnitude faster than prior work (2 bit/min). **Results:** The attack exploits insufficient timer freezing and coarsening in DyPrIs, enabling high-speed data exfiltration. **Impact:** Exposes a severe security flaw in a widely deployed edge computing framework, prompting Cloudflare to deploy V8 Sandbox and MPK-based isolation for mitigation. **Overview:** This paper introduces a new model for Byzantine State Machine Replication (SMR) where commands may be valid only relative to a hidden policy state that validators cannot reconstruct from the log. It addresses the challenge of safely allocating hidden consumable resources under Byzantine leadership, isolating two critical requirements for correctness. **Method:** The authors propose a fair reserve/use protocol with an explicit authorization-witness interface to satisfy authorization safety and first-arrival liveness. The protocol ensures that committed first requests bind later validity, preventing conflicts by making subsequent conflicting requests invalid. **Results:** The work formalizes the two distinct obligations in this one-shot reservation model and demonstrates that the protocol meets both authorization safety and first-arrival liveness under trusted FIFO admission. **Impact:** This advances the field of Byzantine SMR by addressing gaps in handling hidden state and consumable resources, opening new research directions in fair-ordering protocols and hidden resource management.

### [Efficient Byzantine Agreement on L-bit Values with Decoupled Complexity](https://arxiv.org/abs/2608.17552)

<small>**cs.DC updates on arXiv.org** &nbsp;·&nbsp; 2026-08-19 05:00:00 &nbsp;·&nbsp; `byzantine-agreement` `distributed-protocols` `message-complexity` `round-complexity`</small>

**Overview:** This paper extends recent work on Byzantine Agreement (BA) protocols by decoupling the dependency on the number of parties (n) and Byzantine parties (t) in complexity metrics. It focuses on achieving efficient BA for L-bit values while maintaining optimal resiliency. **Method:** Using the framework from Constantinescu et al., the authors introduce novel techniques to generalize BA protocols for L-bit values. They propose deterministic protocols for synchronous, partially synchronous, and asynchronous settings with improved bit and round complexity. **Results:** In synchrony, the protocol achieves O(n·(L + f·κ)) bit complexity and O(f + log n) round complexity. In partial synchrony, it achieves O(f) round complexity with Õ(n·κ + t·(L + f·κ)) bit complexity. In asynchrony, it achieves Õ(n·κ + t·(L + t·κ)) expected bit complexity and O(1) expected latency. **Impact:** This work advances the state-of-the-art in BA protocols, making them more practical for large-scale distributed systems by reducing complexity dependencies and improving scalability.

**Overview:** Proposes Forward-Pass-Only MLP training (FPO), a method for adapting LLMs without backward passes through the model body, achieving 2.7–3.2x throughput and ~40% lower peak memory than standard fine-tuning while maintaining comparable off-domain performance. **Method:** FPO exploits late-layer prediction error as a proxy gradient (cosine similarity 0.47–0.59 with true gradients) and applies a single error signal to target layers without constructing an autograd graph. A two-minute diagnostic identifies viable layers for adaptation. **Results:** Evaluated on OLMo-2-7B, Qwen3-8B, and Falcon3-7B, FPO improves in-domain perplexity while keeping MMLU, ARC-Challenge, HellaSwag, and Winogrande within seed-noise of baseline. Localizing SFT to FPO’s layers achieves similar results at 2.2x higher wall-clock cost. **Impact:** Demonstrates feasibility of high-efficiency LLM adaptation via forward-pass-only signals, opening avenues for memory-constrained training regimes.
