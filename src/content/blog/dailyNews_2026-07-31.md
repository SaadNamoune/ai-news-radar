### [ABSL: Integer-Only Neural Network Learning Algorithm in Rust](https://github.com/Mojo0869/ABSL)

<small>**Hacker News - Newest: "AI"** &nbsp;·&nbsp; 2026-07-31 23:51:20 &nbsp;·&nbsp; `neural-networks` `integer-arithmetic` `embedded-ai`</small>

![ABSL: Integer-Only Neural Network Learning Algorithm in Rust](https://opengraph.githubassets.com/c2427c2d2fc339a24a70fe2b6832be2386e7c9e083463811183232ba8064f9a0/Mojo0869/ABSL)

**Overview:** ABSL (Adaptive BitShift Learning) is an experimental integer-only neural network learning algorithm implemented in Rust, designed for low-power embedded systems and neuromorphic hardware. **Method:** ABSL avoids floating-point operations entirely, using adaptive bit-shift operations to scale weight updates based on integer error magnitude. It employs a 2-4-1 architecture (2 inputs, 4 hidden neurons, 1 output) to mitigate rounding errors from integer quantization. **Results:** On XOR benchmarking, ABSL achieves 98.7% perfect runs, 99.7% global accuracy, and 3.99 average correct cases per run, with 0% total failures (<=2 correct). **Impact:** Advances research in energy-efficient AI for resource-constrained devices. Open questions include scalability to larger networks and broader benchmarks beyond XOR.

### [DoTime: A Scalable Generator for Interventional and Counterfactual Time-Series Causal Models](https://arxiv.org/abs/2607.27263)

**Overview:** This paper introduces **DoTime**, an open-source generator for multivariate temporal structural causal models (TSCMs) with interventions, addressing the lack of interventional and counterfactual benchmarks in time-series causal inference. **Method:** DoTime supports continuous-time intervention windows, counterfactual sampling with positivity guards, regime-switching SCMs, and non-stationary dynamics. It includes four frozen evaluation suites with 100,000 trajectories and eight identification structures. The **dotime** PyPI package provides the generator and suites. **Results:** The paper claims and tests a falsifiable hypothesis: interventional training improves direction-accuracy over observational models of identical capacity. Across three seeds and multiple structures, the interventional prior-fitted network (PFN) shows a positive gap in every test. **Impact:** Foundational tool for causal time-series research, enabling scalable, theoretically grounded evaluations in healthcare, policy, and climate science.

### [FAVA: Formal Authorization for Verified Agents in Dynamic LLM Environments](https://arxiv.org/abs/2607.27267)

<small>**cs.CR updates on arXiv.org** &nbsp;·&nbsp; 2026-07-31 05:00:00 &nbsp;·&nbsp; `agentic-ai` `authorization-framework` `smt-verification` `data-flow-tracking`</small>

**Overview:** FAVA introduces a formal authorization framework for LLM agents operating in dynamic environments where static permissions are insufficient. It addresses the challenge of context-dependent, runtime-state-aware authorization for agentic AI systems. **Method:** FAVA uses an LLM-guided Permission Intermediate Representation (IR) to translate natural-language tasks into structured constraints, which are deterministically lowered into an evidence-backed permission graph tracking data flows and dependencies. A Satisfiability Modulo Theories (SMT) authorizer verifies the graph against security policies before any effectful action executes. A runtime gateway enforces the solver's result, either authorizing execution or intercepting with a counterexample. **Results:** Evaluated on OpenAgentSafety, OctoBench, and ActPlane, FAVA achieves a 90.5% Decision Compliance Rate (DCR), successfully intercepting dynamic violating traces. **Impact:** Advances formal verification for agentic AI, enabling safer autonomous systems in complex environments. Open questions include scalability to larger state spaces and generalization to broader agentic tasks.

### [Extended Stern-Brocot Tree (ESBT): A Compact Identifier Allocation Scheme for Scalable Sequence CRDTs](https://arxiv.org/abs/2607.28101)

<small>**cs.DC updates on arXiv.org** &nbsp;·&nbsp; 2026-07-31 05:00:00 &nbsp;·&nbsp; `CRDTs` `distributed-systems` `collaborative-editing` `identifier-allocation`</small>

**Overview:** This paper introduces the Extended Stern-Brocot Tree (ESBT), a mathematically grounded identifier allocation scheme for distributed collaborative text editing using Sequence Conflict-free Replicated Data Types (CRDTs). It addresses the scalability limitations of existing sequence CRDTs, which suffer from uncontrolled identifier growth and memory consumption during long-running, highly concurrent sessions. **Method:** ESBT provides a dense, deterministic, and compact identifier space by leveraging the Stern-Brocot tree structure to bound identifier growth while preserving Strong Eventual Consistency (SEC). The scheme allocates identifiers in a way that minimizes memory usage and ensures deterministic ordering. **Results:** Experimental evaluation with up to 100,000 concurrent operations across 50 sites shows ESBT improves responsiveness by 28–88% under pure insertions and 59–74% under mixed workloads, while reducing identifier memory consumption by 50–75% compared to Logoot and LSEQ. Under adversarial middle-insertion workloads, ESBT achieves 86.53% responsiveness improvement and 92.81% identifier size reduction. **Impact:** ESBT advances the scalability of sequence CRDTs, enabling efficient large-scale collaborative editing systems with bounded identifier growth and reduced memory overhead.

### [OwlPath: Lossless Structural Code Compression via OWL2 Ontologies for LLM Agents](https://arxiv.org/abs/2607.27249)

<small>**cs.SE updates on arXiv.org** &nbsp;·&nbsp; 2026-07-31 05:00:00 &nbsp;·&nbsp; `code-retrieval` `ontology-reasoning` `software-engineering-agents`</small>

**Overview:** LLM-based software agents struggle with limited context windows when resolving bugs due to inefficient retrieval of structurally relevant code. OwlPath addresses this by encoding source code into an OWL2 ontology to enable precise structural queries, reducing token usage and runtime while improving recall. **Method:** OwlPath integrates with CodeGraph (500K+ GitHub stars) via tree-sitter parsing, supporting multi-language repositories (Python, JavaScript, TypeScript, Go). It uses two modules: (1) a transitive-closure engine for multi-hop structural relations via SPARQL property-path queries, and (2) OWL-SKM, a 3KB precomputed summary of module trees, core APIs, and issue-related symbols. **Results:** On 18 SWE-bench Pro instances, OwlPath achieves a 68.4% strict-apply rate (vs. 66.7% baseline), reduces token usage by 28.8%, and cuts runtime by 39.5%. In offline retrieval tests (67 instances), recall improves 2.06x (0.464 vs. 0.226) with an 88.1% hit rate (vs. 59.7%). On a 37-question structural benchmark, recall rises from 4.4% to 28.8%, with 69-80% accuracy on transitive caller/interface tasks. **Impact:** Advances LLM agent efficiency in software engineering by enabling lossless structural compression, opening new avenues for scalable multi-language code reasoning.

**Overview:** LLM-based workspace agents require lifecycle-wide safety assessment due to stateful, multi-step workflows. AgentS4D introduces a four-dimensional runtime-safety framework to systematically evaluate risks, harms, and evidence across agent execution. **Method:** Evaluates 20 harness-LLM combinations (4 harnesses × 5 LLMs) on 328 risk-injected cases, yielding 6,560 runs. Safety varies by harness-LLM pairing and risk induction strategy. Same induction via different carriers exposes distinct weaknesses. **Impact:** Demonstrates that task completion does not imply safety, urging comprehensive risk-aware evaluations and evidence retention in agent safety research.

**Overview:** This paper addresses the inefficiency of conventional transformer-based surrogate models in low-dimensional engineering design, where overparameterization leads to overfitting and computational overhead. The authors propose **Depth Recursive Transformers** as a hardware-aware alternative, focusing on compute efficiency rather than parameter count. **Method:** Three recursive transformer paradigms are evaluated: Tiny Recursive Model, Depth Recursive Transformer (proposed), and a simple recursive transformer. Results show a trade-off between prediction accuracy, parameter efficiency, and computational cost, outperforming baselines in resource-constrained scenarios. **Impact:** Advances surrogate modeling in engineering by introducing a compute-efficient transformer variant, with implications for FEA and numerical solvers in low-data regimes.

**Overview:** This paper investigates why reinforcement learning (RL)-trained large reasoning models outperform supervised fine-tuned (SFT) models on mathematical reasoning tasks, focusing on internal representational differences. **Method:** The study uses linear probes to evaluate hidden-state predictability of answer correctness and mean ablation to assess layer-wise importance distribution. ### [SmartGen: Selective KV Cache Transfer for Disaggregated LLM Inference](https://arxiv.org/abs/2607.28150)

<small>**cs.DC updates on arXiv.org** &nbsp;·&nbsp; 2026-07-31 05:00:00 &nbsp;·&nbsp; `LLM-inference` `KV-cache` `disaggregated-systems` `network-optimization`</small>

**Overview:** This paper presents SmartGen, a KV cache transfer engine designed to mitigate network bottlenecks in disaggregated LLM inference systems, where prefill and decoding stages are separated across nodes. Transferring full KV caches between stages can saturate limited inter-node bandwidth, especially in self-hosted cloud deployments. **Method:** SmartGen employs three data transfer paths: (1) a profile-based proactive transfer to push essential KV entries during prefill, (2) a parallel on-demand transfer to fetch remote/local KV entries during decoding, and (3) a speculative transfer to deliver all KV caches to the decoding node. The system balances accuracy and performance by selectively transferring only necessary KV cache entries. **Results:** Experimental results show SmartGen reduces time-to-second-token by up to 4.3x compared to full KV cache transfer while maintaining comparable decoding performance and accuracy. **Impact:** SmartGen advances efficient disaggregated LLM inference by reducing network overhead and improving responsiveness, enabling scalable and cost-effective LLM serving in resource-constrained environments.
